# Jesus Delgado Landing

La aplicación y sus archivos de configuración están dentro de `front/`.

## Requisitos

- Node.js 20.9 o posterior
- pnpm 11.13.1 (se puede activar con `corepack enable`)

## Desarrollo

```sh
cd front
pnpm install
pnpm dev
```

La aplicación estará disponible en <http://localhost:3000>.

## Build y producción

```sh
cd front
pnpm build
pnpm start
```

También se pueden ejecutar `pnpm lint`, `pnpm typecheck` e `indexnow` desde `front/`.
